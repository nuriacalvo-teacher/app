# Cuaderno de Lengua 1.º Bachillerato

Unidad autocorregible de Lengua Castellana y Literatura (1.º Bachillerato, preparación PAU):

1. Morfología: análisis morfológico y segmentación
2. Formación de palabras, siglas, acrónimos, extranjerismos y locuciones
3. El sustantivo
4. El adjetivo
5. El tema del texto y la opinión del autor
6. Las lenguas de España y sus hablantes

Incluye simulacro de examen con nota sobre 10.

## Cómo publicarlo con GitHub Pages

1. Sube `index.html` (y este `README.md`) a la raíz del repositorio.
2. En GitHub: **Settings → Pages → Build and deployment → Source: Deploy from a branch**.
3. Elige la rama `main` y la carpeta `/ (root)` y pulsa **Save**.
4. En uno o dos minutos la página estará en `https://TU-USUARIO.github.io/NOMBRE-DEL-REPO/`.

## Notas

- Es un único archivo HTML, sin dependencias que instalar (solo carga las fuentes de Google Fonts).
- Las respuestas y las notas se guardan en el navegador (`localStorage`): se conservan al recargar,
  pero solo en ese navegador y dispositivo. Si se borran los datos del navegador o se usa una ventana
  privada, se pierden.
- En los ejercicios no se puede copiar, cortar, pegar ni arrastrar texto.
